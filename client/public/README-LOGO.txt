Drop the Aatmam Software logo here as:

    aatmam-logo.png

The app loads it as "/aatmam-logo.png" in the sidebar footer and on the login
screen ("Powered by Aatmam Software Pvt. Ltd."). Until the file is present, a
clean text wordmark is shown instead, so nothing looks broken.

A transparent-background PNG about 320x120 px (or any 8:3-ish ratio) looks best;
it's auto-scaled to 24px tall.
